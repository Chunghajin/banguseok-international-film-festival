- 종이 `#f4eddf`, 버건디 `#781f30`, 잉크 `#27231f`. 보조색은 종이의 음영과 읽기 쉬운 회색에 한정한다.

- 종이 질감은 CSS 또는 자체 SVG로 만든다. 외부 인쇄물·다른 웹사이트의 그래픽을 복제하지 않는다.

1. 랜딩: 개막 포스터처럼 보이되 첫 모바일 화면에서 슬로건과 개최 CTA를 보여 준다. 결과 예시는 예시로 표시한다.
2. 설문: 집행위원장 인터뷰/심사 서류의 경험. q2 원문과 5개 빈도 선택지를 그대로 사용한다. 가독성과 응답이 장식보다 우선이다.

4. 결과 발표: 세 수상 부문과 특별상·심사평의 공식 발표문. 긴 HTML 읽기와 짧은 공유 포스터 조형을 분리한다. 이미지 저장/공유는 시안이며 M6 기능과 연결하지 않는다.

작업 파일은 `artifacts/stitch-artdirection/`에만 둔다. 해당 폴더는 Git/Vercel 업로드 제외 대상이다. 기존 Next.js·M5·M6 코드나 브랜치·보안 설정을 변경하지 않는다.

## 재사용할 요소

`assets/`의 아래 SVG는 직접 작성한 벡터이며 외부 웹사이트 그래픽을 복사하지 않았다.

- `laurel.svg`: 비대칭 줄기·잎과 왁스 가장자리. D에서는 큰 브랜드 표장, E에서는 인쇄물의 교정 표장으로 쓴다.
- `circle.svg`: 이중 크레용 원. 단계 번호·D 설문 응답·선정 제목에 적용한다.
- `check.svg`: 낙서 체크. 응답·선정 대기·확정 상태의 보조 표시. 상태는 텍스트로도 구분한다.
- `underline.svg`: 크레용 강조선. 슬로건과 특별상 아래에 한정한다.
- `pixel-star.svg`, `pixel-trophy.svg`: 작은 진행/특별상 기호. 포스터·본문과 경쟁하지 않는 크기만 쓴다.
- `paper.svg`: 희미한 자체 종이 노이즈. 사진이나 외부 텍스처를 사용하지 않는다.

실제 로컬 폰트는 **Nanum Myeongjo 700 / Noto Sans KR 400 / Nanum Pen Script 400**이다. 손글씨는 작은 주석에만 쓴다. 화면 문자를 포함하는 서브셋과 OFL 라이선스를 함께 보존했다. 지금 폰트 파일은 시안 문자만 담으므로 실제 앱에 그대로 복사하지 않는다. 고딕 강조는 브라우저의 합성 굵기를 사용한 시안이며 실제 적용 때 필요한 굵기를 별도로 정한다.

## 실제 검사와 한계

- 격리된 실제 headless Chrome에서 2방향×4화면×3폭(360×800, 390×800, 1280×900), **24개 렌더링 검사 통과**.
- 한글 폰트 3종, 실물 포스터 로딩·비율·ID 매칭, 가로 넘침 없음, 모바일 첫 화면 개최 CTA를 확인했다. 모든 HTTPS를 차단한 상태에서 로컬 폰트·포스터만으로 캡처했다.
- 최종 모바일 첫 후보 포스터 시작: **D 약235px / E 약252px**. 두 방향 모두 설명·검색보다 포스터가 중심이며 이미지 위에 선정 배지를 덮지 않는다.
- **10개 상호작용 검사 통과**: 방향별 라디오 선택·포커스, 후보 변경→선정 대기→확정 표현, 시안 검색 열기·한글 입력·0건·닫기, 실제 이미지404 대체 UI, 마지막 행동이 고정 바 위로 스크롤되는지 확인.
- 비교 페이지의 화면4종·390/1280폭·첫 화면/전체 모드 전환, 모바일 가로 넘침·키보드 포커스를 검사했다. **비교 PNG16개**, 개별 화면24개와 첫 화면 캡처24개·이미지 실패 캡처2개를 남겼다.
- 브라우저 검사 근거: `browser-checks.json`, `gallery-checks.json`. 자동 생성 PNG 외에도 랜딩·설문·선정·결과의 모바일 및 데스크톱 캡처를 직접 열어 검토했다. 월계관과 결과 표제가 닿는 부분을 조정하고 재캡처했다.
- 기존 추적 파일132개의 작업 전후 SHA-256이 같고 브랜치는 main이다. 기존 미커밋 M5 변경은 그대로 보존했다. Next.js·M5·M6·보안 설정·환경 변수·DB·배포는 변경하지 않았다.
- 새 자료·스크립트·문서에서 로컬 비밀값의 실제 일치 및 JWT 형태를 검사해 0건이었다. Git/Vercel의 자격 증명·artifacts 제외를 확인했다. 로컬 비교 서버에서 HTML·PNG·폰트는200, 자격 증명 파일·생성 스크립트는404로 확인했다. 상세 요약은 `verification.json`에 있다.

## 기존 A/B/C 대비

기존은 얇은 괘선과 작은 월계관을 곁들인 단정한 도록·공보·포스터였다. 새 시안은 큰 자체 크레용 월계관을 브랜드의 표장으로 반복하고, 손으로 체크한 심사 서류와 개인이 발행한 공식 발표문이라는 세계를 화면 전체에 연결했다. 실제 영화 포스터를 동일하게 적용해 조형 차이를 비교할 수 있으며, 긴 HTML 발표문과 짧은 공유 포스터를 분리했다. 이전 시안은 삭제하지 않았다.

## 선택 전에 남은 디자인 판단

1. D의 더 큰 손그림과 E의 더 차분한 인쇄물 질서 중 기본 방향을 정한다. 랜딩 D·결과 E처럼 조합할 수도 있으나 아직 앱에는 반영하지 않는다.
2. E 설문은 서류 표제가 있어 작은 화면에서 다음 버튼까지 스크롤이 더 필요하다. D의 빠른 진행과 E의 도록 분위기 중 우선순위를 정한다.
3. 결과용 사용자 이름·최장 영화 제목·6부문 전부 선정한 밀도는 현재 고정 예시보다 늘어난다. 최종 구현 전 실제 콘텐츠 경계값으로 재검토해야 한다.
4. 공유 포스터의 매우 작은 보조 문구는 구도 검토용이다. M6 PNG 코드·해상도·실제 SNS 가독성과 연결하거나 검증한 결과가 아니다.
