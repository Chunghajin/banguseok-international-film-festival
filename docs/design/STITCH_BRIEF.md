## 네 화면의 고정 계약

1. **랜딩**: 정확한 브랜드·슬로건, 개최 CTA, 최소3부문 안내. 결과 샘플에는 반드시 '예시'. 측정하지 않은 예상 시간·가짜 통계 금지.
2. **설문**: 한 화면 한 문항,6문항 진행률, 명확한 이전/다음·건너뛰기. 비교 화면은 q2/6. 원문: '친구에게 인생 영화를 추천한 뒤, 영화보다 친구 표정을 더 열심히 본 경험은 얼마나 있나요?' 선택지: 매우 자주 있다 / 자주 있다 / 가끔 있다 / 드물다 / 전혀 없다. 기본 선택 없음. q4는 동의 척도, q6는 별도 관람 구간이며 이를 다른 척도로 바꾸지 않는다.
3. **영화 선정**: 심사위원장 대상, 설명 '“이게 내 영화다”가 먼저 나오는 작품'. 실제 관람작 안내. 첫 화면 포스터 우선, 2열×3행6편. familiar/cine/discovery 각2편. 기생충(2019), 쇼생크 탈출(1994), 이터널 선샤인(2004), 시네마 천국(1988), 코다(2021),400번의 구타(1959). 원래12편·2페이지·배열 보존 유지. 직접 검색은 보조, 선택 대기와 '이 작품에 수여' 확정은 구분. 포스터 없음/네트워크 오류/제목 두 줄과 연도/하단 겹침 고려.
4. **공식 수상 결과**: 검토용 샘플임을 표시. 최소3부문 결과, 포스터·제목·연도·부문, 특별상·심사평. 샘플은 심사위원장 대상=기생충2019, 평생공로상=나 홀로 집에1990, 친구야 미안했상=멀홀랜드 드라이브2001. 실제 선정·점수 계산 결과라는 주장 금지. 특별상 샘플 '평점 협의상', 원문 심사평 '심사위원 정원은 한 명입니다. 자문위원의 출석 여부는 별도 집계하지 않았습니다.' 로컬 미리보기/미게시 표기. 내 영화제 저장 전용 조작과 공개 읽기 화면을 혼합하지 않는다.

실제6부문과 순서는 심사위원장 대상→평생공로상→친구야 미안했상→두 번은 못 보겠상→다들 좋다는데 모르겠상→아무도 안 줘서 내가 주겠상. 새 상·자유입력·소셜 로그인·공개 탐색·결제·CSV·PNG 완성 버튼을 만들지 않는다.
