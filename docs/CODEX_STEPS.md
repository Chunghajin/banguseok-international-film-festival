- `docs/PRD.md`
- `docs/SCREEN_CONTENT.md`

네 문서의 제목 버전이1.1인지, CHANGELOG가 미승인/승인 중 어느 상태인지 확인한다. 사용자에게 v1.1 기준 개발 지시를 받으면 그 날짜와 기준을 CHANGELOG에 기록한다. v1.0은 이력 보존용이며 개발의 대체 입력으로 섞지 않는다.

```text
6. 실제 파일과 오류 fixture 검증을 통과하지 못하면 버튼을 노출하지 마세요. 일반 경로 회귀 검사를 수행하세요.

완료 기준: 실제 샘플 호환, 원본 비전송, 매칭 확인, 일반 경로 보존. 불충족이면 P1 보류로 기록하고 출시 일정을 늘리지 마세요.
```
