# M1 — 랜딩·영화적 자아 설문·로컬 초안

2026-10-21 · v1.1 기준 사용자 요청 범위. G1·G2·G3 기능 및 보안 코드는 변경하지 않았다.

## 확인 URL

- `http://localhost:3000/`: 랜딩과 로컬 초안 시작/이어쓰기
- `http://localhost:3000/create/survey`: 6문항 설문
- `http://localhost:3000/create/awards`: 설문 완료 체크포인트. 실제 수상작 선정은 준비 중이며 구현하지 않았다.

## 구현한 행동

브랜드와 슬로건 ‘심사위원 만장일치. 심사위원 1명.’을 표시한다. 랜딩의 결과 예시는 SCREEN_CONTENT의 Q02 내용을 사용한 정적 예시이며 결과 계산이 아니다. 읽기 쉬운 종이색·먹색 타이포그래피에 파란 밑줄과 작은 도장을 사용했다. 개발용 G2/G3 화면에는 이 레이아웃이 적용되지 않는다.

문항·응답은 SCREEN_CONTENT를 그대로 사용한다. q1/q2/q3/q5는 빈도 5단계, q4는 동의 5단계이며 내부값은 4→0이다. q6는 7개 관람량 구간이며 51~100편과 101편 이상을 분리한다. 기본 선택은 없고, 답변 없는 ‘다음’은 오류를 표시한다. 명시적인 ‘이 질문 건너뛰기’는 null로 저장한다. 0은 유효한 답변이다. 선택 즉시 이동하지 않으며 이전·다음과 진행률을 제공한다.

로컬 초안은 답변·현재 문항·설문/시상 진입 상태·draft_id·버전·수정 시각을 보존한다. 마지막 수정 후 7일이 지나면 만료 안내를 표시한다. 저장소 비활성화/용량 오류는 경고와 메모리 작성으로 전환한다. 손상/다른 버전의 데이터는 덮어쓰거나 자동 변환하지 않는다. 새로 시작할 때 현재 초안이 있으면 브라우저 확인창을 요청한다. 다른 localStorage 키나 익명 세션은 지우지 않는다.

`banguseok:m1-draft:v1.1` 키는 M1 설문 부분만 저장한다. 후보 TMDB ID·셔플·시상 선택을 임의로 생성하지 않는다. M2에서 전체 LocalDraftV11과 연결할 때 이 키의 draft_id·답변·진행 상태를 이관하고 회귀 검증해야 한다. 이는 전체 영화제 저장 모델이나 서버 저장의 완성이 아니다. 초안은 이 브라우저의 평문 저장소이며 기기 간 동기화/복구 기능은 없다.

접근성은 본문 바로가기, 한국어 문서 언어, native radio/fieldset/legend, 연결된 오류 메시지, 키보드 포커스, 질문 전환 시 제목 포커스, 색상 외 선택 표시를 사용한다. 주요 버튼 56px, 보조 버튼 최소 44px이며 도움말도 14px 이상으로 표시한다.

### Chrome 360×800에서 직접 조작한 항목

- 랜딩 슬로건·시작 버튼과 좁은 화면의 타이포그래피를 확인했다.
- 빈 답변으로 다음을 누르면 진행이 차단되고 오류가 표시됐다.
- radio에서 키보드 아래 화살표로 선택을 변경했다.
- q2의 값 0을 선택한 뒤 새로고침했을 때 q2·선택·진행률 2/6이 복원됐다.
- 이전/다음으로 q1·q2의 기존 선택이 유지됐다.
- q3 건너뛰기와 q4 동의 선택지 5개·중간값 2 선택을 확인했다.
- q6의 51~100편을 선택하고 완료했다. 완료 화면도 새로고침 후 복원됐다.
- 설문 재편집으로 q6에 돌아와 선택을 확인하고 101편 이상으로 바꿔 다시 완료했다.
- 입구로 돌아왔을 때 ‘이어서 개최하기’가 표시됐다.

화면 증거: [랜딩 360px](../artifacts/m1/landing-360.jpg), [설문 360px](../artifacts/m1/survey-360.jpg).

‘새로 개최하기’의 native 확인창을 조작하는 중 브라우저 자동화 연결이 시간 초과로 중단됐다. 확인창 취소/승인 후 보존/초기화 동작은 브라우저 통과로 기록하지 않는다. 저장 실패·만료·버전 불일치는 단위 테스트로만 확인했다.

## 미구현·미검증

실제 시상 선택·후보 셔플·특별상 점수 계산·DB 저장·결과 생성·공개 URL 연결은 구현하지 않았다. 새 의존성이나 환경변수는 추가하지 않았다. G1/G2/G3 실검증 전체를 이번 작업에서 재실행하지 않았으며 기존 단위 테스트는 함께 통과했다.

실제 iOS/Android, VoiceOver/TalkBack, 전체 breakpoint/자동 axe 검사, 재시작 확인창 취소·승인, Vercel 배포는 미검증이다. 로컬 360px Chrome을 실제 휴대전화 검사로 해석하면 안 된다. 다음 단계 전 확인창과 실제 휴대전화의 키보드·스크롤·새로고침을 확인한다.
